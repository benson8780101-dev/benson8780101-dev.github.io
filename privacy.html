Privacy Policy

Benson Assistant for fun — last updated September 27, 2026

Who uses this app

This app is a personal assistant used only by its owner. It is not offered to the public, and no one else is invited to sign in.

What data it accesses

With the owner's permission, the app reads the owner's own Gmail, Google Drive, Docs, Sheets, Tasks, Contacts and Calendar, and can add events to the owner's own Google Calendar. It does not send email and does not change or delete files.

How the data is used and stored

  • Data is used only to answer the owner's own requests, such as "What is on my calendar tomorrow?"
  • Sign-in tokens are stored only on the owner's own computer.
  • Data is not sold, shared with third parties, or used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Access can be removed at any time at myaccount.google.com/permissions.
